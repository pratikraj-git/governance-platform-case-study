# Design Principles

Visual style:
- restrained enterprise SaaS
- minimal decorative styling
- sophisticated hierarchy
- operational clarity
- dense but readable
- premium systems presentation

Use:
- modular layouts
- subtle interactions
- editorial spacing
- architecture visuals
- governance diagrams
- zoomable workflows

Avoid:
- gradients
- glassmorphism
- flashy animations
- excessive motion
- heavy storytelling gimmicks
